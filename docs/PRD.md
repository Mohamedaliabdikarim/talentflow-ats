# TalentFlow ATS — Product Requirements

**Status:** Phase 0 (planning). No requirement is implemented or verified yet.  
**Source of truth for requirement status:** the table in this file. `docs/TEST_PLAN.md` holds the evidence.

## 1. Goal

A first-customer-ready, multi-tenant applicant tracking system. A platform admin provisions customer organizations and their users. Customer users manage jobs and candidates and move applications through a compact Kanban pipeline. Platform admins can perform every customer operation inside a selected customer workspace. Tenant isolation is enforced in PostgreSQL with row level security (RLS).

## 2. Personas

| Persona        | Description                                                  | Primary goals                                                                                |
| -------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Platform admin | Employee of the ATS vendor                                   | Create customers, invite users, support customers inside their workspace, grant admin rights |
| Customer user  | Recruiter or hiring manager at a customer organization       | Post jobs, add candidates, run the pipeline                                                  |
| Candidate      | Person being considered for a job (not a user of the system) | Represented by a record only                                                                 |

## 4. Out of scope for the first delivery

- Candidate-facing portal or public job board.
- Email notifications beyond Supabase Auth messages.
- Resume parsing, automatic ranking, automatic rejection.
- LinkedIn data extraction of any kind.
- Billing, SSO, custom pipeline stages per organization.

## 5. Non-functional requirements

- **Security:** see `docs/SECURITY.md`. No elevated key reaches the browser. Negative authorization tests are mandatory.
- **Accessibility:** WCAG 2.2 AA targets for contrast, focus, keyboard operation, reduced motion. See `docs/DESIGN.md`.
- **Performance:** first contentful paint under 2 s on a typical broadband connection for the pipeline page with 200 applications.
- **Language:** everything in English.
- **Observability:** health endpoint, structured server logs without personal data.
